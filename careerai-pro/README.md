# CareerAI – Premium AI Career Coach

Production-grade SaaS application for AI-powered career coaching.

## Features

- 🔐 Email & Google Authentication
- 💳 Razorpay Payments (Daily ₹9, Monthly ₹49, Yearly ₹99)
- 🤖 Multi-AI Support (Gemini + Grok)
- 💬 Career guidance with flowcharts & salary data
- 📱 Fully Responsive (320px – 1920px)
- ♿ WCAG 2.2 AA Accessible
- 🔒 Security: Helmet, Rate Limiting, CORS, XSS Protection
- 📊 SEO Optimized with JSON-LD, OpenGraph, Twitter Cards

## Deployment

1. Clone the repository
2. Add environment variables in Vercel dashboard
3. Deploy with `vercel --prod`

## Environment Variables

See `.env.example` for required variables.
